# Project information

## Know the tools

### Python

- A popular language for writing backend programs and tests.
### FastAPI

- A widely used Python framework for building web APIs.

### Docker

- A common tool that packages and runs apps in containers.

### Dockerfile

- A standard recipe Docker follows to build an image.

### compose.yaml

- The standard file describing services Docker Compose starts together.

### SQLAlchemy

- A common Python toolkit for working with SQL databases.

### PostgreSQL

- A widely used database that stores and queries application data.

### Alembic
- SQLAlchemy's standard tool for tracking database changes.

### Psycopg

- A standard driver connecting Python programs to PostgreSQL.

### Redis

- A common fast data store for caches and queues.

### redis-py

- The standard Python client for talking directly to Redis.

### Celery

- A common Python tool for running background jobs.

### Celery Beat

- Celery's built-in scheduler for recurring jobs.

### Pydantic

- A common Python library that checks incoming data.

### Pydantic Settings

- A standard Pydantic tool for reading application settings.

### Pytest

- A widely used tool for running Python tests.

### HTTPX

- A common Python HTTP client used in FastAPI tests.


## Key concepts

### JSON
- A simple, universal text format - like a Python dictionary - used to send data between a server and an app.

### Server
- A server is a computer or program that stays running to store data, run backend code, and send responses whenever an app or browser asks for something.

### CORS (Cross-origin resource sharing)

- A standard browser rule controlling requests between different origins.

## JWT-Authentication (JSON Web Token Authentication)

### JWT

- A JSON Web Token (JWT) is a compact string that carries claims about an identity or request.

### Claim

- A claim is a named piece of information inside a token.

### Authentication

- Authentication checks who is making the request.

### Authorization

- Authorization checks what that person or service is allowed to do.

### Access Token

- An access token is a credential sent with requests to an API.

### Refresh Token

- A refresh token lets the client request a fresh access token without another password prompt.

### HS256

- HS256 uses one shared secret to create and verify a token's signature.

### Secret Key

- A secret key is random private data the server uses to sign and verify HS256 tokens.

### Password hashing

- Password hashing turns a password into a stored value that can be checked without storing the original.

### Argon2

- Argon2 is a password hash designed to make repeated guessing expensive.

### Salt

- A salt is random data added by the password hasher so identical passwords produce different hashes.

### OAuth 2.0

- OAuth 2.0 defines how an application can obtain limited access to a protected resource.

### Protected route

- A protected route checks credentials or permissions before returning private information or performing an action.

### ID token

- An ID token tell a client application who signed in.

### OAuth2PasswordBearer

- A FastAPI dependency that reads a bearer token from the request and describes its scheme to OpenAPI (Swagger)

### sub, exp

- These claims name the token's subject and the time after which it expires.

### iss, aud

- These claims identify who issued the token and which API should accept it.


## CI & CD (GitHub actions)

### CI (Continuous integration)

- Continuous integration (CI) automatically builds and tests changes before they merge.

### CD (Continuous delivery)

- Continuous delivery (CD) automatically prepares a release that you can deploy when ready.

### CD (Continuous deployment)

- Continuous deployment (CD) automatically rolls out a passing release to a running environment.


### actions/checkout

- actions/checkout downloads one's GitHub repository's code onto the running machine so the workflow can build, test or deploy it.

### GitHub Container Registry (GHCR)

- GitHub Container Registry is a private or public storage that allows to upload, manage and download one's Docker container images alongside the code. 

### GitHub SHA

- GitHub SHA is a unique 40-character ID generated by Git to identify and track every single snapshot of changes in the code.
